
# Conversion Landing WebApp - Premium Edition

This project is a high-conversion landing page designed for professional services. It follows the "International Agency" aesthetic: dark mode premium, high-impact typography, and a strategic conversion funnel.

## 🎯 Project Objective
The primary goal is to generate qualified leads. The application enforces a mandatory lead capture form (Name + Email) before allowing the user to redirect to the expert's WhatsApp.

## ✨ Features
- **Premium Dark Design**: High-contrast, elegant colors and deep gradients.
- **Conversion-First UX**: All page elements point to the main CTA.
- **Lead Capture Funnel**: Integrated modal validation before external redirection.
- **Mobile First**: Fully responsive layout optimized for smartphones.
- **Service-Oriented Logic**: Mock portfolio and structured benefits section.

## 🛠️ Stack
- **React 18+** with TypeScript
- **Vite** (Build Tool)
- **Tailwind CSS** (Styling)
- **Services Pattern**: Dedicated modules for WhatsApp logic and form submission.

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/conversion-landing-webapp.git
   ```

2. **Navigate to the folder**:
   ```bash
   cd conversion-landing-webapp
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
